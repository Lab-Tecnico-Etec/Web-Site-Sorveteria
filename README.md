# Sorveteria — Projeto de Programação Web

Projeto acadêmico coletivo desenvolvido no contexto da disciplina de Programação Web da ETEC.

## Tecnologias

- HTML
- CSS
- JavaScript

## Estrutura

- `index.html` — página inicial
- `Cardapio.html`, `Feed.html`, `Sobre.html` — páginas do projeto
- `CSS/` — folhas de estilo
- `js/` — scripts de interface
- `imgs/` — recursos gráficos (em consolidação)
- `Fonts/` — fontes e licenças disponíveis

## Estado da consolidação

Os arquivos HTML, CSS, JavaScript, textos de licença, fontes e recursos binários identificados foram copiados da origem, com uma exceção: `imgs/imgs/Logo1.png` (arquivo grande que não pôde ser recuperado pela integração disponível). **A migração está quase completa, mas ainda precisa ser validada:** esse recurso pode aparecer quebrado se for referenciado pelo site. Copie o arquivo ausente da origem antes de considerar a consolidação integral.

## Como executar

Abra `index.html` em um navegador moderno. Para avaliação fiel, use um servidor HTTP local e confira caminhos relativos, imagens, fontes e comportamento das páginas depois da migração dos recursos.
